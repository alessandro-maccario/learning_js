# PIG GAME Flowchart

## User Rolls Dice

1. Generate random dice roll
2. Display dice roll
    2a. Is it a 1?
        - NO -> Add dice roll to current score and display new score
        - YES -> Switch Player

## User Holds Score

1. Add current score to total score
2. Is the score >= 100?
    - YES -> Current player wins!
    - NO -> Switch Player

## User Resets Game

1. Set all scores to 0
2. Set player 1 as starting player
